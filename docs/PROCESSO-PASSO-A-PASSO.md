# SENTINELA DAS ÁGUAS · APP · fluxo passo a passo

Aplicação web para visualizar alertas, mapas e inspeções.

## 1. ABRIR PAINEL

Carregar a aplicação web e consultar a página de alertas.

## 2. FILTRAR LOCALIZAÇÃO

Selecionar área ou ponto de interesse nos filtros.

## 3. VISUALIZAR NO MAPA

Consultar pontos e informações de risco exibidos na interface.

## 4. REGISTRAR INSPEÇÃO

Usar telas de inspeção e relatórios conforme os dados disponíveis.

## 5. REVISAR ALERTAS

Conferir informações e validar com fontes e responsáveis locais.

## Resultado e limites

Interface em desenvolvimento. A Home é demonstrativa e não comprova sensores ou alertas reais.
