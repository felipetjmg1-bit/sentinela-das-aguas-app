# Índice de documentação — Sentinela das Águas

## Sobre o projeto

Sentinela das Águas é um protótipo web para visualização de alertas e pontos de monitoramento relacionados a enchentes. A interface e os documentos servem como base de pesquisa e desenvolvimento. Não é, neste estágio, um serviço operacional de alerta público ou uma plataforma validada para decisões de emergência.

## Como avaliar o projeto

1. Comece pelo README.md e identifique o que existe no código.
2. Separe funcionalidades implementadas, simulações, propostas e itens pendentes.
3. Consulte os testes e workflows para identificar o que foi efetivamente executado.
4. Não use métricas estimadas ou exemplos como resultados reais.
5. Não utilize o protótipo em operações de emergência sem validação independente e implantação apropriada.

## Maturidade

**Estado: protótipo em desenvolvimento.** O projeto requer testes de integração, validação de dados, avaliação de segurança, medições de desempenho e piloto controlado antes de qualquer alegação de prontidão operacional.
